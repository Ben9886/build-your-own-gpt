# Learning Log

One short entry per session. Source material for interview answers like *"tell me about something you learned recently"* or *"walk me through a tricky bug you debugged."*

Format per entry:

```
## YYYY-MM-DD — Episode N, Section X

**What I built today:** one sentence.

**What clicked:** the concept I now understand that I didn't before.

**What surprised me / what's still fuzzy:** the bit I had to re-watch, or a question I can't yet answer.

**If I were writing this for production:** what I'd change (perf, numerical stability, API design).
```

Keep entries to ~6 lines. The point is portfolio-grade reflection, not a diary.
